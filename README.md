# ML Math

Exercises for Mathematics / Machine Learning studies.

## Pandas exercises

This repository contains solutions for the first 7 exercises from the Pandas `Series` chapter.

### Exercises

1. Monthly test scores
2. Scaling grades
3. Tens digit extraction
4. Descriptive statistics
5. Monday temperatures
6. Taxi passenger counts
7. Short, medium and long taxi trips

## Technologies

- Python
- NumPy
- Pandas
- Google Colab
- Jupyter Notebook
